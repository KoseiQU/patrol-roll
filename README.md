# パとるロール — デモ版

市民参加型インフラ点検プラットフォームのデモ用静的 PWA。

> **デモ版注記**: AI 危険度判定はシミュレーションです（本番は Claude Haiku 4.5 を想定）。  
> データは端末内の IndexedDB / localStorage にのみ保存されます。サーバー・API キー不要。

---

## 機能一覧

### 市民モード
- 📸 写真撮影 / ライブラリ選択 / デモ写真で道路異常を報告
- 🤖 AI 危険度スコア（0〜100）とカテゴリ（要確認 / 経過観察 / 低リスク）のリアルタイム演出
- 🗺 全画面マップにピン表示（カテゴリ色・パルスアニメ）
- 📋 詳細シート：写真・スコアリング・AI 見立て・対応タイムライン・「なおして!」応援ボタン
- 👤 プロフィール：レベル / XP / ランク / 8 種バッジ / カプセルトイガチャ（モック）
- 🔔 通知センター：バッジ獲得・修繕完了・レベルアップなど
- ⚙️ 設定：モード切替 / Web 通知許可 / デモリセット

### 技術者モード（設定 → 技術者モードに切替）
- 🛠 技術者ダッシュボード（フルスクリーン）
  - KPI カード：未対応 / 要確認(高) / 今週の新規 / 修繕完了率
  - **リスト**タブ：AI スコア降順・フィルタ（ステータス / 種類）・「▶ 次へ進める」でステータス一発更新
  - **マップ**タブ：ヒートマップトグル付き
  - **定点ウォッチ**タブ：30 m 以内に複数件ある地点をクラスタリング、スコア推移スパークライン＋悪化トレンド矢印（↗赤）、タップで時系列シート
- 詳細シートにもステータス変更ボタンが出現
- 自分の報告が修繕完了になると +200 XP / +30 🎟 ＋コンフェッティ演出

## 動かし方

```bash
cd patrol-roll
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

> **注意**: 位置情報・カメラは `localhost` または `https` で動作します（`file://` 不可）。

### セルフテスト

```
http://localhost:8000/?selftest=1
```

ブラウザの開発者ツール → コンソールで `[selftest] DONE pass=N fail=0` を確認してください。

### Netlify へのデプロイ

1. [Netlify](https://app.netlify.com/) にログイン
2. **Sites → Add new site → Deploy manually**（または **import from Git**）
3. `patrol-roll/` フォルダをドラッグ＆ドロップ（`index.html` がルートにある状態）
4. 数秒でデプロイ完了。`https://xxxx.netlify.app` でアクセスできます

ビルドステップ・環境変数は不要です。

## ローカル JS / CSS のバージョン管理

`index.html` の `<script src="js/xxx.js?v=N">` と `<link href="css/xxx.css?v=N">` のクエリパラメータ `v=N` で
ブラウザキャッシュをバストします。JS や CSS を変更してリリースする際は N を上げてください
（現在値は `index.html` を参照。**Service Worker や CDN URL 内の文字列は変更不要**）。
あわせて `sw.js` 先頭の `V` も上げるとオフラインキャッシュも確実に世代交代します。

## データについて

- すべてのデータはこの端末内（IndexedDB / localStorage）にのみ保存されます。
- サーバーへの送信は一切ありません。位置情報を URL パラメータに載せません。
- IndexedDB が使えない環境（iOS プライベートブラウズ等）はメモリ内フォールバックで動作します。

## 本番移行メモ（DESIGN.md §12 参照）

| 箇所 | デモ版 | 本番 |
|---|---|---|
| AI 判定 | `js/ai.js` ルールベースシミュレーション | Lambda + Anthropic Claude Haiku 4.5（バッチ＋プロンプトキャッシュ） |
| データ永続化 | `js/store.js` IndexedDB | API Gateway + DynamoDB / PostGIS バックエンド（インターフェース互換） |
| 通知 | アプリ内 + Web Notification API | Web Push / Amazon SNS |
| 認証 | ニックネームのみ（localStorage） | Amazon Cognito ユーザープール |
| 地図タイル | CARTO Voyager（デモ用途） | 商用タイルプロバイダ（CARTO 商用契約または MapTiler 等） |
